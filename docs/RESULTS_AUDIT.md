# Audit of the original submission report

The original report is preserved separately for historical context. The points below should be kept in mind when reading it.

1. **Annualized default probability:** the report's 39.33% ten-year scenario probability converts to about 4.87% annualized under its stated constant annual probability conversion, not approximately 7%.
2. **Stress-scenario captions:** the table reports 39.33% default and 3.28% cash-out; a figure description refers to roughly 51% defaults. The heatmap's 52.4% result is a separate 5,000-path experiment.
3. **High-initial-spread scenario:** the table reports 96.25% cash-out, while a figure description says approximately 98%.
4. **Base case:** the summary table reports 34.99% cash-out, while the final-NAV figure discussion rounds it to 37%.
5. **Default intensity:** the original formula includes a risky-duration divisor. Its suitability should be assessed in the exact model convention before treating outputs as financially meaningful.
6. **Historical and ratings claims:** historical rating assignments and market peak claims require independent sourcing. Simulated classifications are not external ratings.
7. **Data limitation:** the original CDX sample begins after the 2007–2009 financial crisis. Hypothetical shocks are not historical backtests.
8. **Data provenance:** source terms for market data are not established; raw files are deliberately excluded from this public repository.

This is an audit of inconsistencies and assumptions, not a replacement validation exercise.
